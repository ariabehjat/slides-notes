Release Notes

Everything new, version by version. Grab the latest from the home page.

Latest

Version 1.4.0

September 22, 2026
  • Manual page breaks in Notes Press ⌘-Return while writing a standalone note to jump straight to the top of the next page — a real gap between the two sheets, not just a printed line.
  • Full color picker for folders and documents Pick any color, not just a preset swatch, for a folder or document tag — and subfolders/documents now pick up a lighter, inherited version of their parent's color automatically. The notes text-color menu got the same treatment, including a custom-color option.
  • Drag folders and documents to reorder them Manual sort mode now shows a real insertion-line indicator as you drag, and drops actually move things — previously dragging did nothing.
  • Sidebar reveals where things are Creating or moving a document into a folder now expands that folder into view instead of leaving it hidden behind a collapsed row, and opening the app to your last document makes its folder location clear right away.
  • Auto-bullet on "-" Start a line with "- " in a note and it turns into a bullet, the same shorthand as Word or Markdown editors.
  • Document notes live next to the PDF on disk A PDF's whole-document note now sits in the same folder as the PDF itself, and existing notes are migrated there automatically. Restructuring a synced folder's subfolders is now picked up too, or refreshed on demand with "Refresh Synced Folder."
  • Fixes The app icon no longer renders larger than other apps' icons, and the notes formatting toolbar's buttons respond again.

Version 1.3.1

September 16, 2026
  • Reveal Synced Folder in Finder A synced folder's context menu now jumps straight to the original Finder folder being watched.
  • Notes are easier to get to outside the app Fixed "Reveal in Finder" silently doing nothing for standalone Notes documents. A PDF's whole-document note is now also kept as a real, standalone file — a new "Reveal Document Note in Finder" action opens it directly in TextEdit, Word, or anywhere else.

Version 1.3.0

September 13, 2026
  • Page notes are now real PDF comments, two-way A note pinned to a page is saved as a genuine PDF comment — visible and editable in Preview, Acrobat, or anywhere else the file is opened. Edit it there, reopen it here, and the change is already waiting for you. Comments added in other apps show up in the notes panel too. The icon itself sits quietly in the bottom-right corner of the page and never appears in our own reading view — your notes still live in the panel, exactly as before.

Version 1.2.0

September 13, 2026
  • Synced Folders Point Slides & Notes at a Finder folder and it stays in sync — new PDFs added to it (or its subfolders) while the app is open import automatically, no re-importing by hand.
  • Search a folder, or your whole library Find every document that mentions a word or phrase — searches PDF text, OCR'd scans, and your notes, with a snippet so you can tell matches apart at a glance.
  • A real find bar ⌘F now opens an in-document find bar with a match count, previous/next buttons, and every occurrence highlighted on the page — the current match is always clearly marked as you step through.
  • Multi-select in the sidebar ⌘-click or ⇧-click documents and folders to move or remove several at once.
  • Sort by name, date, kind — or drag things into your own order Manual sort mode lets you drag documents and folders into exactly the order you want, and it sticks.
  • Folders are browsable Selecting a folder now shows what's inside it — subfolders and documents, one click from opening — instead of a blank pane.
  • Drag a Finder folder straight into the sidebar Dropping a real folder onto the sidebar now imports it, the same as "Import Folder…" — it previously did nothing at all.
  • Clearer import summaries Importing a folder that contains non-PDF files (like .pptx) now tells you exactly what was skipped, so nothing silently goes missing.

Version 1.1.0

September 12, 2026
  • First-launch setup Choose This Mac or iCloud Drive for your library the first time you open the app.
  • Library packaged as a single icon Your library now shows up in Finder as one document-style icon (a real macOS package, like .app or .pages) instead of an expandable folder full of subfolders — right-click ▸ Show Package Contents to look inside.
  • Send Feedback A menu item that opens your mail client, pre-addressed.
  • Split-view tab strip Two documents shown side by side now render as one merged pill in the sidebar, like tabs in a split-view browser.
  • Smarter notes panel Page notes fade in and out based on where you're scrolled to (with a "Show All" toggle), and voice notes are folded directly into the document and page note sections.
  • Fixes The highlight-color picker now shows the actual colors instead of plain black dots.

Version 1.0.0

September 11, 2026
  • Initial release Real PDF-native highlights, a notes panel beside the document, on-device OCR, voice notes and dictation, browser-style split view, folders and colour tags, and Markdown exam-prep export — all offline, all free.
