# Slides & Notes

Landing page + downloadable installer for **Slides & Notes**, a free, offline
macOS app for reading and highlighting PDFs, with on-device OCR, rich notes,
voice recordings, and exam-prep export.

- Download: see [Releases](https://github.com/ariabehjat/slides-notes/releases)
